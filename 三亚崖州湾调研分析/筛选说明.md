## 二、口径及其对研究的含义

口径为**注册企业名录**——在园区办理登记的全部市场主体，而非入驻企业或高企遴选名单。
名录含银行支行、通信营业店、酒店、药房、百货商行、眼镜店分公司等。

因此下面这个分布**不是筛选噪音，而是这份数据的实质结论**：

| | 家数 | 占比 |
|---|---|---|
| 核心赛道（南繁种业 686 + 深海海洋 218） | 904 | **6.01%** |
| 支撑性硬科技 | 503 | 3.34% |
| 泛农业经营（种植/养殖/农资/林畜） | 384 | 2.55% |
| 明确非目标（贸易/文旅/建筑/药房/百货等） | 6,800 | 45.21% |
| **批量注册特征** | **2,181** | **14.50%** |
| 泛科技名称但无行业信号 | 1,448 | 9.63% |
| 名称信息不足待判 | 2,692 | 17.90% |

"批量注册特征"指形如「三亚市＋2–3 个人名样字＋网络科技有限公司」的成串近似名称，
如 三亚市终涵蕾 / 姚洁锟 / 童博昕 / 戎文要 / 任默兴 / 马子格 / 缴鸥 / 计乐容 / 衡斐晖…
**这一组按研究设计单独成组保留，不予剔除**——在"注册企业名录"口径下，
它恰是注册驱动型增长最直接的观测量。

## 三、由信用代码派生的两个变量

### 1. `origin` 首次登记地

代码第 3–8 位为登记机关行政区划代码，**企业迁址后该代码不变**，
故标识"出生地"而非当前住所，可用于区分**本地新设**与**外地迁入**。

| origin | 家数 | 占比 |
|---|---|---|
| 本地（海南省级登记 460000） | 10,690 | 71.07% |
| 省内迁入/外设（海口及其他市县） | 2,546 | 16.93% |
| 本地（三亚市/区 4602xx） | 1,465 | 9.74% |
| 省外迁入/外设 | 340 | 2.26% |

核心赛道 × 首次登记地交叉：南繁种业 130 家省内迁入 + 16 家省外迁入；深海 41 + 5。

### 2. `vintage` 注册年代近似

代码第 9–17 位为组织机构代码。纯数字为 2015 年前旧版（老企业 362 家，2.41%）；
`MA` 开头为 2015 年后新版，`MA5 → MAK` 大致按启用时间递增。
名录末尾新增段集中为 `MAK`，与该排序假设一致。

**这是序数近似，不是成立日期**，不可作连续变量入回归；
用途限于粗切"政策窗口期注册"队列。

## 四、筛选规则与分层

关键词表见 `screen.py` 顶部，可直接引用以说明筛选可复现。三条特殊规则：

1. **育种科技与泛农业经营分列两类**。「种业/种子/育种/种源/物种/南繁」归核心赛道；
   「农业/农资/林业/畜牧/果业」归泛农业经营。二者对"引导基金培育科创企业"
   不是同一回事，混为一谈会高估科技培育效果。
2. **具名龙头覆盖关键词逻辑**。`隆平生物技术（海南）有限公司` 名称不含任何赛道词，
   纯关键词法会漏掉。故对中种、隆平、先正达、大北农、垦丰、荃银、九圣禾等
   具名主体强制归入核心赛道。
3. **赛道词与经营词冲突单独成类**（112 家）。如「海南南繁文化有限公司」含"南繁"
   但主营文化，不计入核心赛道。

## 五、D 层漏检率：两轮抽样验证

D 层 4,140 家不逐一人工判定，改用随机抽样估计漏检率。

**第一轮**（n=400，seed 20260217，`d_labels.py`）：核心赛道漏检 **9.00%**
（95%CI 6.57–12.21%）。漏检呈系统性——35 条种业漏检中约 20 条名称只写"农业"
而无"农业科技"，其余为 种源 / 物种 / 林业 / 畜牧 / 果业 / 粮 / 椰子 / 农资。
据此扩充关键词表并新增泛农业经营类。

**第二轮**（n=300，**seed 99991，与调规则轮独立**，`d_labels_v2.py`）：

| 判定尺度 | 核心赛道漏检 | 支撑赛道漏检 | 合计 |
|---|---|---|---|
| STRICT（名称含明确行业词） | 2.33% [1.13, 4.74] | 2.67% [1.36, 5.17] | 5.00% [3.05, 8.08] |
| LENIENT（含仅凭暗示性字的存疑判定） | 9.00% [6.26, 12.78] | 8.33% [5.71, 12.01] | 17.33% [13.47, 22.02] |

核心赛道漏检率由 9.00% [6.57, 12.21] 降至 2.33% [1.13, 4.74]，**两区间不重叠，改进显著**。

STRICT 尺度下推断 D 层仍遗漏核心赛道企业约 97 家（区间 47–196）。

**残余漏检不能靠继续加关键词解决**，因为名称本身已无信息。典型案例：

- `海南华大智造科技有限公司` —— 基因测序装备龙头，名称无任何行业词
- `镭测创芯（海南）科技有限公司` —— 激光测量＋芯片
- `海南意波量子科技有限公司` —— 量子
- `菽新生物科技（三亚）有限公司` —— "菽"即豆类
- `中农动科（三亚）技术有限公司` —— 动物科学
- `海南深水能源有限公司` —— 深水即深海油气

要突破这一层，必须引入**工商登记经营范围**字段，名称法到此为天花板。

## 七、本名录不能支持的推断

- **无法判断是否获投**。名录无股东字段，L1–L5 分层（标杆/成长/获投平淡/
  未获投对照/疑似空壳）必须在股东穿透之后完成。本文件是抽样框，不是投资状态。
- **`origin` 不等于实体所在地**。信用代码不随迁址变更：省外代码只证明"首次登记在省外"，
  不能据此断定企业实体不在三亚；省级代码也不能证明实体在园区。
  例：`中国种子集团有限公司` 代码为 `91110000100000438C`（北京首次登记），
  同时另有 `中国种子集团有限公司三亚分公司`（三亚登记）——
  该公司是否已实迁三亚，须查工商变更记录，不能由代码推断。
- **"批量注册特征"是名称形态判断，不是空壳认定**。认定空壳需社保人数、
  实际用电用水、研发人员本地社保、本地固定资产等实体性指标。
- **已知残留误判**：`中国船舶重工…第七六〇研究所海南分部` 结尾为"分部"，
  未被分支机构正则捕获，`form` 标为独立法人。实为分支机构。
